Model

Mode n oscillates at νn = (n + offset)·c/2L, where c/2L = 15 GHz·(1 cm / L). All widths set in GHz are converted to units of this mode spacing before solving; the comb shown covers ±50 modes and has intensity In in units of Isat. Its round-trip loss defines the loss line, normalised to 1. Steady state means every oscillating mode has saturated gain exactly equal to the loss; a mode with In = 0 must have gain below the loss. The solver iterates this condition mode by mode until it converges.

Homogeneous line. One shared inversion, Lorentzian line ℓ(ν) = 1/[1 + (2ν/Γ)²]. Gain of mode n: gn = P ℓn / [1 + ℓnIn + θ Σm≠n ℓmIm]. Without spatial hole burning θ = 1, every mode saturates the same inversion, all oscillating modes would need the same ℓ, and only the mode closest to line centre survives. With spatial hole burning the standing-wave patterns of different modes overlap only partly, and the cross-saturation coefficient drops to θ = 2/3 (self term ⟨4 sin⁴⟩ = 3/2, cross term ⟨2 sin²⟩² = 1). Since θ < 1, several modes can coexist.

Etalon. An etalon of free spectral range FSR and finesse 𝓕 has transmission T(ν) = 1/[1 + F sin²(π(ν − νe)/FSR)] with F = (2𝓕/π)². Mode n then sees loss an = 1/T(νn) in place of 1, and the steady-state condition becomes gn = an. The peak width is FSR/𝓕. To force a single mode the peak must be narrower than about two mode spacings and the FSR must exceed the width of the region where the gain beats the loss.

Inhomogeneous line. Gaussian envelope of FWHM equal to the Doppler width, each velocity class with a Lorentzian response of FWHM Γ. Mode m burns a hole of width Γ at νm: the inversion of class ν′ is N₀(ν′)/[1 + Σm Im L(ν′ − νm)]. Modes further apart than about Γ do not compete, so many modes oscillate. This is a rate-equation model without mode pulling, and cross-saturation between modes uses the mean standing-wave overlap; the numbers are qualitative.
