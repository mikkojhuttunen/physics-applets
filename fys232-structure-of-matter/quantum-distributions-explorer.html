Model and notes

B is fixed by the particle number: B = e−μ/kBT. For fermions at T → 0, μ → EF = ε, so ℕ(E) becomes a step at ε. In Fixed N mode each distribution gets its own B such that Σℕ(Eₙ) = N over the equally spaced levels, which reproduces the three-temperature comparison in the lecture example.

In Fixed B mode all three curves use the same μ. This isolates the effect of the +1, −1 and 0 in the denominators. Bose–Einstein requires μ below the ground-state energy, so the slider is clamped for that curve only.

The classical limit holds when every occupation number is far below 1. That is the case for kBT ≫ ε and it fails for cold, dense systems such as the conduction electron gas.
